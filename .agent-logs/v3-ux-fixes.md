## Review judgments and limits

1. Metadata filtering is local; full transcript search is a separate explicit flow.
2. Seed repair runs on backend startup, but only for complete known fingerprints. A title match alone never permits a rewrite/deletion. User-modified demos require manual review.
3. Speaker bars represent an estimate of participation rather than recorded audio duration. There is no audio diarization/end-time data in the schema.
4. Native dialog supplies modal background inertness; explicit keyboard handling traps Tab and Shift+Tab. The drawer covers both nav surfaces.
5. English-only action labels were selected instead of partial localization.
6. Production database was not directly accessible. Local SQL plus deployed API evidence established the defect. No deployment or production repair was performed; live data remains unchanged until separately authorized deployment.
7. Existing toolchain warnings remain: missing Next ESLint plugin configuration, Vite CJS deprecation, python_multipart deprecation. npm install reported 13 dependency advisories; no unrelated dependency upgrade was attempted.
