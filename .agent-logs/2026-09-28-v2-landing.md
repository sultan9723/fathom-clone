- Header, hero, language comparison, eight language cards, text-only integrations,
  privacy section, final CTA, and footer.
- Join demo types each of three platform URLs, detects the hostname, advances
  through Join / Joining / Joined and Listening, then loops. It pauses offscreen
  or when the tab is hidden, and includes a manual pause control.
- Desktop scroll story with a pinned stage, five clickable steps, progress bars,
  word streaming, target-script scramble, source highlights and summary items,
  bilingual Q&A, and a working source preview with focus handling.
- Stacked, fully resolved steps on mobile, short viewports, and reduced motion.
- Existing color, font, radius and motion tokens reused. Button, Badge and Panel
  primitives reused without modification. Landing overrides button transitions
  to opacity/transform and uses clip overflow to allow the sticky stage.
- No packages added. No shared tokens, fonts, primitives, motion helpers, app
  routes, API modules, backend files, or meeting-detail files changed by this task.
